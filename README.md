# 🦝 Solfeggio Binaural Generator

A web-based binaural beats generator featuring the nine sacred Solfeggio frequencies.

## What is this?

This is a pure HTML/JavaScript application that generates binaural beats using the Web Audio API. Binaural beats are an auditory illusion created when two slightly different frequencies are played separately to each ear through headphones. The brain perceives the difference between these frequencies, which can induce various mental states.

## How to Use

1. **Put on stereo headphones** - Binaural beats require separate frequencies in each ear
2. **Select a frequency** - Click the play button on any frequency card
3. **Adjust settings**:
   - Master Volume: Control overall loudness (start low!)
   - Carrier Frequency: Base tone frequency (default: 432 Hz)
   - Timer: Set automatic fade-out time
4. **Relax and enjoy** - Each frequency has unique properties

## ⚠️ Important Warnings

- **Headphones Required**: Binaural beats only work with stereo headphones
- **Start at Low Volume**: Protect your hearing - start quiet and increase gradually
